# Security policy

## Supported versions

Security fixes are provided for the latest v2 release.

## Reporting a vulnerability

Please use this repository's **Security → Report a vulnerability** flow so details remain private while the issue is investigated. Include reproduction steps, affected files or workflows, and the likely impact. Do not open a public issue for an unpatched vulnerability.

Configuration is treated as untrusted content. Reports about escaping, unsafe URL handling, workflow permissions, dependency compromise, or generated-file boundaries are especially useful.
