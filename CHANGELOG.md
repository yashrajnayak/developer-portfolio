# Changelog

All notable changes follow [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and semantic versioning.

## [2.0.0] - 2026-08-08

### Added

- Schema v2 with editor autocomplete, strict validation, duplicate detection, HTTPS and asset checks.
- Build-time HTML, SEO, JSON-LD, sitemap, manifest, site README, and profile README generation.
- DevRel-oriented hero, impact strip, structured case studies, recent-role timeline, compact proof band, curated work, and focused contact CTA.
- Sticky responsive navigation, persistent light/dark themes, native disclosures, reduced-motion support, and 44px touch controls.
- Unit, HTML, link, local-path, Playwright, and axe validation at mobile, tablet, and desktop viewports.
- Official GitHub Pages deployment, beginner setup workflow, Dependabot, contribution guide, security policy, and issue templates.

### Changed

- Made `dist/` the deployable output and JavaScript progressive enhancement only.
- Replaced runtime GitHub ranking with an intentionally curated work list.
- Consolidated content into a central person and portfolio schema.

### Removed

- Client-side rendering of core portfolio content.
- Floating theme and scroll-to-top controls.
- Competing README auto-commit workflows.

### Compatibility

- Schema v1 configurations remain readable through the built-in v1-to-v2 migration for the v2 major release.
